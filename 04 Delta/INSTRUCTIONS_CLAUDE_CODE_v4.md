# Инструкции для Claude Code — деплой Hall of Fame v4

## Контекст
Hall of Fame v3 (с каруселью) уже задеплоен. Обновляем до v4 — добавляем:

1. **Карусель: фильтр `active`** — баннеры можно скрывать через колонку в Sheets без удаления
2. **Страница `tickets.html`** — публичный лидерборд билетов с топ-3 на подиуме и поиском
3. **Страница `wheel.html`** — закрытая страница колеса розыгрыша (доступ по коду, не в открытом доступе)

## Что нужно от пользователя

Перед началом получи у пользователя **четыре значения**:

1. **CSV_URL** (победители) — уже есть в текущем `index.html`, бери оттуда
2. **CURRENT_PRIZES_CSV_URL** — уже есть в текущем `index.html`
3. **TICKETS_CSV_URL** — новая, от Codex (лист `Tickets`)
4. **CONFIG_CSV_URL** — новая, от Codex (лист `Config`)
5. **TWITCH_URL** — уже есть в `index.html`

В `tickets.html` подставляются:
```javascript
const TICKETS_CSV_URL = "...";  // от Codex
const CONFIG_CSV_URL = "...";    // от Codex
const HOME_URL = "./";           // оставь как есть, ведёт на главную
```

В `wheel.html` подставляются:
```javascript
const TICKETS_CSV_URL = "...";   // тот же что в tickets.html
const CONFIG_CSV_URL = "...";    // тот же что в tickets.html
```

В `index.html` — переменные не меняются по сравнению с v3.

## Что делать

### Шаг 1. Обнови `index.html`

Просто скопируй новый `index.html` поверх старого. Изменился только парсер карусели (добавлен фильтр `active`). Уже подставленные CSV-ссылки и TWITCH_URL нужно сохранить — либо подставь их заново в новый файл, либо сравни и перенеси.

### Шаг 2. Добавь `tickets.html`

Скопируй новый файл `tickets.html` в корень репозитория. Подставь:
- `TICKETS_CSV_URL`
- `CONFIG_CSV_URL`
- `HOME_URL` оставь как `"./"` — это относительная ссылка на `index.html`

### Шаг 3. Добавь `wheel.html`

Скопируй `wheel.html` в корень репозитория. Подставь:
- `TICKETS_CSV_URL` (тот же)
- `CONFIG_CSV_URL` (тот же)

**ВАЖНО:** не делай нигде ссылок на `wheel.html`! Это секретная страница. На неё пользователь будет заходить только через закладку в браузере. Никаких ссылок ни в `index.html`, ни в `tickets.html`.

### Шаг 4. Локальная проверка

```bash
python3 -m http.server 8000
```

Проверки:

**`http://localhost:8000/index.html`** (главная):
- ✅ Карусель работает как раньше
- ✅ Если в `CurrentPrizes` поставить `active=FALSE` для всех — карусель полностью скрывается

**`http://localhost:8000/tickets.html`** (билеты):
- ✅ Топ-3 на подиуме (1 место в центре крупнее, 2 слева, 3 справа)
- ✅ Остальные 4-20 места в сетке снизу
- ✅ Таймер до розыгрыша работает (если `raffle_active=TRUE` в Config)
- ✅ Поиск по нику фильтрует и показывает позицию найденного
- ✅ Ссылка "← Hall of Fame" возвращает на главную

**`http://localhost:8000/wheel.html`** (колесо):
- ✅ Без кода — экран с полем ввода password
- ✅ С верным кодом — открывается интерфейс колеса
- ✅ Колесо рендерится с пропорциональными секторами по билетам
- ✅ Кнопка "Один победитель" — крутит, показывает оверлей с победителем
- ✅ Кнопка "Режим выбывания" — крутит, выбывший удаляется из колеса, повтор нажатия — следующая крутка, пока не останется один
- ✅ Длительность вращения переключается 3/5/10 сек
- ✅ Кнопка "Сброс" возвращает всех участников
- ✅ Кнопка "Перезагрузить" — подтягивает свежие данные из Sheets

### Шаг 5. Запушь все три файла

```bash
git add index.html tickets.html wheel.html
git commit -m "v4: tickets system, secret wheel page, carousel active flag"
git push origin main
```

GitHub Pages обновится за 1-3 минуты.

## Известные технические детали

- **Колесо использует SVG** для рендера. Анимация — CSS `transform: rotate()` с `transition`. Работает плавно даже при 100+ участниках.
- **Текст на тонких секторах сокращается** или вообще не показывается (если сектор меньше 2°). Минимальный размер сектора — 1.5°, чтобы участник с 1 билетом не был полностью невидимым на колесе с 1000 билетов.
- **Авто-обновление**: страница `tickets.html` тянет данные раз в минуту. Если пользователь добавил кому-то билеты в Sheets — через минуту обновится на странице.
- **Wheel.html не авто-обновляется** во время розыгрыша — только по кнопке "Перезагрузить билеты". Иначе данные могли бы меняться прямо во время вращения.
- **Кодировка:** все три файла UTF-8 без BOM. Если после копирования через какой-то редактор возникли кракозябры — открой в VS Code, проверь кодировку в правом нижнем углу, при необходимости "Save with Encoding → UTF-8".
- **Безопасность кода колеса:** код хранится в публикованной CSV. Технически можно найти через DevTools. Это барьер от случайных посетителей, не серьёзная защита. Имя файла `wheel.html` и отсутствие ссылок — основная защита.

## Если что-то пошло не так

**Таймер не показывается на tickets.html:**
- Проверь что `raffle_active=TRUE` в листе `Config`
- Проверь формат `raffle_date` — должен быть `YYYY-MM-DD HH:MM`
- Проверь что `CONFIG_CSV_URL` правильно подставлен

**Колесо не пускает при правильном коде:**
- Проверь что код в Sheets совпадает с введённым символ-в-символ (регистр важен!)
- Открой DevTools → Console — там видны ошибки загрузки

**На колесе нет участников:**
- Проверь что в листе `Tickets` есть строки с `silver > 0` или `gold > 0`
- Скрипт игнорирует участников с `score=0`

**Карусель показывает все баннеры даже с `active=FALSE`:**
- Проверь, что `TRUE`/`FALSE` написано с большой буквы или в стандартном формате
- Также подходят: `true`, `false`, `yes`, `no`, `1`, `0`, `да`, `нет`
