# Как устроен сайт

Статический сайт: обычные HTML-страницы, CSS и JavaScript без сборки, фреймворков и `npm`.
Хостинг — GitHub Pages (бесплатно, обновляется примерно через минуту после коммита).
Данные — JSON-файлы в репозитории; админка сохраняет их коммитами через GitHub API.

## Папки

```
*.html            страницы сайта; их адреса не меняются (на них ссылаются OBS, закладки, зрители)
core/             ядро: общее для всех страниц
kits/             детали, которые используют несколько разделов
modules/<раздел>/ код и стили страниц раздела
data/             данные сайта, правятся в админке
bridge/           мост на компьютере стримера (донаты «Боли», модификаторы для OBS), Node.js
docs/             документация
.github/          роботы GitHub Actions: обложки заказов, часы Steam, картинки друзей, данные «Боли»
img/ sounds/ friends/ experiments/   картинки и звуки
*.json в корне    файлы, которые пишут роботы (orders-meta, pain-meta, steam, friends-meta), и experiments.json
```

### core/ — ядро

| Файл | Что делает |
|---|---|
| `core.js` | Общие функции: `esc`, `plural`, `parseCSV`, `hof.json/table/kv/config`, `siteData`. Подключается первым на каждой странице и в каждом оверлее. |
| `site.js` | Разделы и профиль (`siteModules`, `siteProfile`), верхнее меню, иконки (`icon()`), сезонная тема, время (`siteTime`). Подключается сразу после `core.js` на страницах с меню. |
| `theme.css` | Цвета и шрифт сайта. Единственное место, где они заданы. |
| `site.css` | Общий вид страниц сайта: шапка, фильтры, карточки, метки. Сам подключает `theme.css` и `nav.css`. |
| `nav.css` | Стили верхнего меню. |
| `gate.css` | Экран входа по коду на страницах стримера. |
| `github.js` | Чтение и запись файлов репозитория через GitHub API (`siteGit`), вход на страницы стримера (`siteGit.gate`). |
| `winter.css`, `winter-ice.svg` | Зимняя тема (включается в админке: «Настройки» → «Оформление»). |

### kits/ — общие детали

| Файл | Кто использует |
|---|---|
| `wheel-kit.js`, `wheel-kit.css` | Колесо рулетки: рулетка заказов, чат-рулетка, «Боль», настройки рулеток в админке |
| `chat-kit.js` | Настройки и режимы чат-оверлея: `chat.html` и вкладка «Чат» в админке |

### modules/ — разделы

Правило имён: `<страница>.page.js` и `<страница>.page.css` — код и стили одной страницы.
Файлы без `.page` — общий код раздела для нескольких его страниц.

## Как устроена страница

```html
<head>
  <link rel="stylesheet" href="core/site.css?v=7">            <!-- или theme/nav/gate.css у рулеток -->
  <link rel="stylesheet" href="modules/hall/hall.page.css?v=1">
  <script> /* настройки страницы (если есть): ссылки на данные, списки */ </script>
</head>
<body>
  <script src="core/core.js?v=1"></script><script src="core/site.js?v=20"></script>
  ... разметка ...
  <script src="modules/hall/hall.page.js?v=1"></script>
</body>
```

`?v=N` — номер версии файла. Браузеры и OBS держат копии файлов; поменял файл — подними `?v=` во всех подключениях, иначе часть зрителей увидит старую версию.

Оверлеи OBS (`chat`, `screen`, `mods`, `iguana`) держат в HTML строку `const VERSION = '...'`: оверлей сам сверяет её со свежей копией страницы и перезагружается. При правке оверлея подними и `VERSION`, и `?v=` у его `.page.js`.

## Данные

- `data/*.json` — всё, что правится в админке. Формат: `{ "columns": [...], "items": [{...}, ...] }`, одна запись на строку.
- `data/config.json` — настройки сайта и профиль стримера (ключи `streamer_*`, `site_season`, расписание, рулетки).
- `data/modules.json` — разделы: название в меню, группа, порядок, включён ли, `private` (видит в меню только вошедший стример; тайный вход в админку: зажать имя в меню на секунду).
- `data/cards.json` — копия базы рулетки хаоса (пишет сама `cards.html`).
- Новому коду: `hof.table('anime')` — записи раздела, `hof.config()` — настройки.

## Правила

1. Функция, нужная больше чем одной странице, живёт в `core/core.js` (или в `kits/`), а не копируется.
2. Цвета — только переменными из `core/theme.css` (`var(--gold)` и т.д.).
3. Ник, канал, пояс и прочее о стримере — из `siteProfile`, не из кода.
4. Адреса страниц (`*.html` в корне) не менять: на них настроены OBS и закладки.
5. Иконки — SVG из `core/site.js` (`icon('name')`), без эмодзи.
