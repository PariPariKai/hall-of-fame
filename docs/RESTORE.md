# Переустановка Windows или новый компьютер

Короткая инструкция, как вернуть всё для стрима. Разбираться в коде не нужно.

## Что где живёт

| Что | Где | Что будет при переустановке |
|---|---|---|
| Сайт и все его данные (заказы, зал славы, правила, чат, заставки) | GitHub, репозиторий `PariPariKai/hall-of-fame` | Ничего. Сайт работает сам, компьютер ему не нужен |
| База карточек рулетки (`cards.html`) | В браузере, копия на сайте: `data/cards.json` | Подтянется с сайта сама, когда откроешь рулетку |
| Ключи Steam, Twitch, Anthropic для роботов | Секреты репозитория на GitHub | Ничего, они на GitHub |
| Код моста (донаты «Боли», модификаторы для OBS) | Репозиторий, папка `bridge/` | Скачается вместе с репозиторием |
| Ключи DonationAlerts, копилки и таймер «Боли» | Только этот компьютер: `bridge/config.json`, `bridge/data/` | **Пропадут без бэкапа** |
| Сцены и профили OBS (все источники, ключ стрима) | Только этот компьютер: `%APPDATA%\obs-studio\basic` | **Пропадут без бэкапа** |
| Токен GitHub для админки | В браузере | Пропадёт, но делается новый за 2 минуты |

## Перед переустановкой: бэкап

Дважды щёлкни `bridge\backup.cmd`. В папке «Документы\Stream backup» появится архив `stream-backup-дата.zip`.
**Скопируй его на флешку или в личное облако.** Внутри ключи DonationAlerts и ключ стрима OBS: никому не отправляй и никуда не выкладывай.

Лучше делать бэкап раз в месяц и после того, как менял сцены OBS.

## После переустановки

1. **Поставь программы.**
   - [Git](https://git-scm.com/download/win) (все галочки по умолчанию).
   - [Node.js](https://nodejs.org/) версии LTS, не ниже 22. Мосту больше ничего не нужно.
   - OBS Studio.

2. **Скачай репозиторий.** Открой PowerShell в папке, где он будет лежать (например, `F:\Streaming`), и выполни:
   ```
   git clone https://github.com/PariPariKai/hall-of-fame.git
   ```

3. **Верни ключи и копилки моста.** Из архива бэкапа скопируй `bridge\config.json` и папку `bridge\data` в папку `hall-of-fame\bridge`.
   Бэкапа нет? Не страшно, но копилки начнутся с нуля:
   - запусти мост (шаг 4), открой http://localhost:3777/admin;
   - впиши Client ID и Client Secret приложения DonationAlerts (их видно в кабинете DonationAlerts, раздел приложений; адрес возврата `http://localhost:3777/da/callback`) и нажми «Подключить»;
   - копилки и таймер, если надо, выставь там же вручную.

4. **Запусти мост.** Дважды щёлкни `bridge\install-autostart.cmd`. Мост встанет в автозагрузку и запустится. Проверка: http://localhost:3777/admin открывается.

5. **Верни OBS.** Закрой OBS. Из архива скопируй содержимое папки `obs-basic` в `%APPDATA%\obs-studio\basic` (вставь этот путь в адресную строку проводника). Запусти OBS: сцены, источники и профиль на месте.
   Бэкапа нет? Источники нужно добавить заново, список ниже.

6. **Подключи админку.** На GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Доступ только к репозиторию `hall-of-fame`, права Contents: Read and write. Вставь токен на https://pariparikai.github.io/hall-of-fame/admin.html. Тот же токен открывает рулетки, «Суд» и «Боль»: в OBS его надо вставить один раз в поле кода на каждой из этих страниц.

## Источники OBS

Сайт: `https://pariparikai.github.io/hall-of-fame/`. Все оверлеи это «Браузер» 1920×1080 с прозрачным фоном.

| Источник | Адрес |
|---|---|
| Чат | `chat.html?o=<id оверлея>` (id и настройки на вкладке «Чат» в админке) |
| Модификаторы рулетки | `mods.html` (параметры: `?pos=tr`, `?scale=1.7`) |
| Рулетка карточек для зрителей | `cards.html?stream` |
| Заставки | `screen.html?s=start`, `screen.html?s=brb`, `screen.html?s=end` |
| Игуана | `iguana.html` |
| Рулетка «Боли» для зрителей | `pain.html?stream` (пульт: админка, раздел «Боль») |
| Таймер «Боли» в углу | `http://localhost:3777/widget` |
| Копилки и таймер крупно | `http://localhost:3777/overlay` |

## Если что-то не работает

- **Оверлей модификаторов или «Боль» не видят мост.** Проверь, что открывается http://localhost:3777/admin. Не открывается: запусти `bridge\start.cmd`, в окне будет видно ошибку.
- **Журнал моста:** `bridge\data\bridge.log`.
- **Сайт показывает старое.** GitHub Pages обновляется около минуты после сохранения, OBS держит копию страницы до 10 минут.
