# Установка сайта для своего стрима

Сайт работает на GitHub Pages: бесплатно, без сервера и без программирования.
Нужен только аккаунт на [GitHub](https://github.com). Все настройки дальше делаются в админке сайта.

## 1. Свой репозиторий

1. Зарегистрируйся на GitHub (или войди).
2. Создай новый репозиторий: «+» вверху справа → **New repository**.
   - Имя, например, `hall-of-fame`. Оно войдёт в адрес сайта.
   - **Public** (GitHub Pages бесплатно работает только с открытыми репозиториями).
3. Загрузи в него все файлы этой папки. Проще всего через GitHub Desktop, или на странице репозитория → **Add file → Upload files** (перетащи содержимое папки, не саму папку).

## 2. Включить сайт

1. В репозитории: **Settings → Pages**.
2. Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save.
3. Через 1–2 минуты сайт откроется по адресу `https://<твой-ник>.github.io/<имя-репозитория>/`.

## 3. Ключ для админки

Админка сохраняет правки прямо в репозиторий, для этого ей нужен личный ключ (токен) GitHub.

1. GitHub → аватарка → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. Название любое, срок действия по желанию (истечёт — сделаешь новый).
3. Repository access: **Only select repositories** → твой репозиторий.
4. Permissions → Repository permissions → **Contents: Read and write**.
5. Generate token, скопируй его.
6. Открой `admin.html` на своём сайте и вставь токен. Он хранится только в этом браузере.

## 4. Настроить под себя (админка)

- **Настройки → Стример:** имя, ссылка на Twitch (по ней работают чат-оверлей и рулетки по чату), аватарка, часовой пояс, ссылка на донат, приветствие на главной.
- **Настройки → Доступ к рулеткам:** придумай код. С ним рулетки, карточки и «Боль» открываются без токена, например в OBS.
- **Настройки → Оформление:** сезонная тема (зима).
- **Разделы:** выключи то, что не нужно (например, «Фильмы», если не смотришь кино на стриме), переименуй пункты меню, поменяй порядок.
- **Расписание:** дни и время стримов.
- Остальные вкладки: заказы зрителей, зал славы, билеты, правила, шаблоны, заставки, чат-оверлей.

Цвета сайта (необязательно): файл `core/theme.css`, переменные `--gold`, `--bg` и другие. Правится прямо на GitHub (карандаш на странице файла).

## 5. Оверлеи для OBS

Все оверлеи: источник «Браузер», 1920×1080, адрес на твоём сайте.

| Что | Адрес |
|---|---|
| Чат | `chat.html` (настраивается во вкладке «Чат» админки) |
| Заставки | `screen.html?s=start`, `?s=brb`, `?s=end` |
| Рулетка хаоса для зрителей | `cards.html?stream` |
| Модификаторы рулетки | `mods.html` |
| Рулетка «Боли» для зрителей | `pain.html?stream` |
| Игуана | `iguana.html` |

## 6. Роботы (необязательно)

Роботы GitHub Actions сами подтягивают обложки и данные. Без ключей они просто пропускают свою работу.
Ключи добавляются в репозитории: **Settings → Secrets and variables → Actions → New repository secret**.

| Секрет | Что даёт |
|---|---|
| `TWITCH_CLIENT_ID`, `TWITCH_CLIENT_SECRET` | Обложки игр из IGDB, когда Steam не нашёл игру (ключи — dev.twitch.tv, раздел приложений) |
| `STEAM_API_KEY` | Часы в играх на карточках заказанных игр (ключ — steamcommunity.com/dev/apikey; плюс SteamID в «Настройках») |
| `ANTHROPIC_API_KEY` | Смешные подписи на обороте новых карточек заказов (ключ — console.anthropic.com, платно) |

Обложки фильмов и аниме, ссылки на Steam и Кинопоиск находятся и без ключей.

## 7. Мост донатов (необязательно)

Нужен для «Боли» (крутки за донаты DonationAlerts) и для модификаторов рулетки в OBS, если рулетка открыта в другом браузере.
Работает на твоём компьютере. Подробно: [bridge/README.md](../bridge/README.md).

1. Поставь [Node.js](https://nodejs.org/) LTS.
2. Скачай репозиторий на компьютер (GitHub Desktop или `git clone`).
3. Дважды щёлкни `bridge/install-autostart.cmd`. Мост запустится и встанет в автозагрузку.
4. Открой http://localhost:3777/admin:
   - **Сайт:** впиши адрес своего сайта;
   - **DonationAlerts:** создай приложение в кабинете DonationAlerts (адрес возврата `http://localhost:3777/da/callback`), впиши ID и ключ, нажми «Войти в DonationAlerts»;
   - **Правила:** цены круток, метки, время.

Бэкап ключей моста и сцен OBS — `bridge/backup.cmd`, как всё восстановить — [docs/RESTORE.md](RESTORE.md).

## Если что-то не так

- **Сайт показывает старое:** GitHub Pages обновляется около минуты, OBS держит копию до 10 минут.
- **Админка не принимает токен:** проверь, что у токена есть доступ к этому репозиторию и права Contents: Read and write.
- **Как устроен код:** [docs/ARCHITECTURE.md](ARCHITECTURE.md).
