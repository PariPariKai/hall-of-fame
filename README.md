# Hall of Fame — сайт стримера

Сайт-инструмент для стримера и зрителей: зал славы, заказы, рулетки, правила, оверлеи для OBS и админка.
Статический сайт на GitHub Pages, без сборки.

- [Установка для другого стримера](docs/INSTALL.md), чистый шаблон собирается командой `node tools/make-template.mjs`
- [Как устроен сайт](docs/ARCHITECTURE.md) — папки, файлы, правила
- [Переустановка Windows или новый компьютер](docs/RESTORE.md)
- [Мост донатов и модификаторов](bridge/README.md)
