# Мост: донаты «Боли» и модификаторы для OBS

Локальная программа на Node.js, работает только на компьютере стримера (`http://localhost:3777`):

- слушает DonationAlerts и DonateX, копит донаты с метками `#боль` и `#время`, хранит оплаченные крутки и таймер игры;
- передаёт модификаторы и таймеры из `cards.html` в оверлей `mods.html` (`/api/mods`), если рулетка и OBS открыты в разных браузерах.

## Что в git, а что только на этом компьютере

| Что | Где | В git? |
|---|---|---|
| Код моста | `server.js`, `public/`, `*.cmd`, `start-hidden.vbs` | да |
| Ключи DonationAlerts/DonateX, цены, метки | `config.json` (создаётся сам при первом запуске) | **нет** |
| Токен входа DonationAlerts | `data/da-token.json` | **нет** |
| Копилки, таймер, история круток | `data/state.json` | **нет** |
| Журнал | `data/bridge.log` | нет |

`config.json` и `data/` закрыты от git в `.gitignore` в корне репозитория. Не убирай эти строки: там токены.
Чтобы не потерять копилки и ключи при переустановке Windows, сохраняй копию `config.json` и папки `data/` (см. `docs/RESTORE.md`).

## Страницы (открываются, пока мост запущен)

| Адрес | Зачем |
|---|---|
| http://localhost:3777/admin | Подключения, ключи, правила, ручная правка, журнал донатов |
| http://localhost:3777/pain | Переадресует на рулетку `pain.html` на сайте (`?stream` — вид для OBS) |
| http://localhost:3777/pain-classic | Старая рулетка моста, запасная |
| http://localhost:3777/widget | Маленький таймер «Боли» для угла экрана в OBS |
| http://localhost:3777/overlay | Счётчик копилок и таймер на прозрачном фоне для OBS (`?only=banks` или `?only=timer` — один блок) |

Пульт «Боли» (крутки, таймер) теперь в админке сайта, раздел «Боль». Она говорит с мостом напрямую.

## Правила

- `#боль` — в копилку игры. Набралось 1 000 ₽ → +1 крутка игры, остаток уходит в копилку времени.
- `#время` — в копилку времени. Набралось 250 ₽ → +1 крутка времени (добавляет время к последней игре).
- Крутка игры заблокирована, пока таймер прошлой игры не на нуле.
- Таймер хранится в мосту: закрытие браузера или выключение ПК его не сбрасывает (при выключении он встаёт на паузу).
- Первое подключение сервиса: все старые донаты помечаются как учтённые, считаются только новые.
- Донаты, пришедшие, пока мост был выключен, досчитываются при запуске (последние 50 на каждом сервисе).

## Запуск

- `install-autostart.cmd` — добавить в автозагрузку Windows и запустить.
- `uninstall-autostart.cmd` — убрать из автозагрузки.
- `start.cmd` — запуск с окном, чтобы видеть ошибки (если мост уже запущен, второй сразу закроется).
- `backup.cmd` — архив с `config.json`, `data/` и сценами OBS в «Документы\Stream backup». Как всё вернуть: `docs/RESTORE.md`.
- Журнал: `data/bridge.log`. Состояние: `data/state.json`.
