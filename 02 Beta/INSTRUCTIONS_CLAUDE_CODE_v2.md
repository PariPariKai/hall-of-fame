# Инструкции для Claude Code — обновление Hall of Fame v2

## Контекст
Hall of Fame v1 уже задеплоен на GitHub Pages. Теперь нужно заменить `index.html` на новую версию с фичами:
- Новый ранг **Эпическая** (фиолетовый, 7%)
- Модификатор **Уникальный** (радужная рамка, переворот при ховере, картинка приза)
- Сортировка по дате (новые сверху)
- Поиск по нику
- Звук включён по умолчанию

## Что делать

### Шаг 1. Подставь CSV-ссылку в новый `index.html`

В файле найди:
```javascript
const CSV_URL = "PASTE_YOUR_GOOGLE_SHEETS_CSV_URL_HERE";
```

Подставь ту же CSV-ссылку, что использовалась в v1 (она не меняется при добавлении колонок). Если у пользователя ссылки нет под рукой — она лежит в его старом `index.html` (можно посмотреть в существующем GitHub-репозитории).

### Шаг 2. Локальная проверка

Из папки с новым `index.html`:
```bash
python3 -m http.server 8000
```
Открой `http://localhost:8000` — должны загрузиться карточки с обновлённым видом. Проверь:
- Эпические карточки появляются (если в Sheets есть записи с `rank=epic`)
- Поиск по нику работает (вверху, рядом с фильтрами)
- Сортировка по дате (новые сверху)
- Фильтр "✨ Уникальный" — отбирает только уникальные карточки
- Если есть тестовая уникальная карточка — на ней радужная рамка, и при ховере она переворачивается, показывая картинку приза

### Шаг 3. Замени файл в репозитории и запушь

```bash
# В папке клона репозитория
cp /путь/к/новому/index.html ./index.html
git add index.html
git commit -m "Hall of Fame v2: epic rank, unique modifier, search, sort by date"
git push origin main
```

GitHub Pages пересоберёт сайт за 1-3 минуты. Сообщи пользователю, что обновление развёрнуто.

## Важные технические детали

- **Колонки в Sheets могут быть в любом порядке** — скрипт ищет их по имени, не по позиции
- **Старые записи без новых колонок продолжат работать** — `unique` пустой = обычная карточка
- **Ранги, отличные от epic/legendary/artifact, отфильтровываются** — если кто-то впишет в Sheets `rare` или другое значение, оно просто не попадёт на стену
- **CSV-ссылка не меняется** при добавлении колонок в Google Sheets — никаких перенастроек публикации не требуется

## Известные особенности

- 3D-флип карточки требует свободного места по бокам — если уникальная карточка в самом крайнем столбце сетки, при перевороте может слегка задеть соседнюю. Это нормально, в большинстве случаев не заметно.
- Звук работает только после первого взаимодействия пользователя со страницей (политика автозапуска аудио в браузерах). Это не баг — после первого клика всё работает.
