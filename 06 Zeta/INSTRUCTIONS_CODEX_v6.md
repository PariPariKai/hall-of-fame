# Инструкции для Codex — обновление Google Sheets для Hall of Fame v6

## Контекст
Hall of Fame v6 — это **рефакторинг безопасности**, не новые фичи. Со стороны Google Sheets изменение **минимальное**: удалить один секрет из публичного листа.

**Что меняется:**
1. Строка `wheel_access_code` удаляется из листа `Config` — пароль больше не лежит в открытом CSV
2. **Всё остальное в таблице остаётся как есть** — структура листов, колонки, ссылки на публикации

**Почему так:**
- `Config` лист публикуется как CSV, который читается сайтом. Это значит что любой пользователь, открыв F12 в браузере, мог увидеть ссылку на Config CSV и прочитать пароль рулетки
- Теперь пароль захэширован (SHA-256) и захардкожен прямо в коде `wheel.html`. Браузер хэширует то что вводит пользователь и сравнивает с этим хэшем
- В открытом виде пароля нет нигде

---

## Шаг 1. Открыть лист `Config`

В существующей таблице открой лист `Config`. Его структура:

| key | value |
|-----|-------|
| raffle_date | 2026-XX-XX HH:MM:SS |
| raffle_title | До розыгрыша Subnautica 2 |
| raffle_active | true |
| tickets_banner_url | https://... |
| **wheel_access_code** | **PariPariWheel** ← эту строку удалить |

---

## Шаг 2. Удалить строку `wheel_access_code`

1. Найди строку, где в колонке `key` стоит `wheel_access_code`
2. Удали **всю строку целиком** (правый клик по номеру строки → Удалить строку)
3. **Не удаляй другие строки** — `raffle_date`, `raffle_title`, `raffle_active`, `tickets_banner_url` нужны для работы таймера на странице билетов

**Итоговая структура `Config` после удаления:**

| key | value |
|-----|-------|
| raffle_date | 2026-XX-XX HH:MM:SS |
| raffle_title | До розыгрыша Subnautica 2 |
| raffle_active | true |
| tickets_banner_url | https://... |

---

## Шаг 3. НЕ нужно перепубликовывать `Config`

CSV-публикация листа продолжает работать автоматически. Ссылка `CONFIG_CSV_URL` для `tickets.html` остаётся прежней — просто теперь в CSV будет на одну строку меньше.

**Проверь:** открой `CONFIG_CSV_URL` напрямую в браузере. Убедись, что:
- Строки `raffle_date`, `raffle_title`, `raffle_active`, `tickets_banner_url` присутствуют
- Строки `wheel_access_code` **нет**

## Замечания

- **Зачем такая мелкая правка отдельной задачей?** Потому что если оставить пароль в Config, то вся работа Claude Code по хэшированию пароля в коде теряет смысл — кто-то может просто пойти и прочитать пароль в Config CSV.
- **Если пользователь захочет поменять пароль рулетки в будущем** — это уже **не задача Codex'а** (Sheets тут не участвует). Пользователь сам или с помощью Claude вычисляет SHA-256 нового пароля и обновляет константу `WHEEL_ACCESS_HASH` в `wheel.html`. Инструкция как это сделать есть в комментарии в шапке `wheel.html`.
- **Если случайно удалил другие строки `Config`** — таймер на странице билетов сломается. Восстанови строки или попроси пользователя восстановить из истории Google Sheets (Файл → История версий).
- **CSV-ссылки на остальные листы (`Winners`, `Tickets`, `CurrentPrizes`, `Viewers`)** — не трогаем, не меняем, не перепубликовываем. Всё остаётся как было.
