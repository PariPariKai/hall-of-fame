# Инструкции для Codex — настройка Google Sheets для Hall of Fame

## Задача
Создать (или подготовить существующую) Google Sheets таблицу для хранения победителей рулетки рангов **Артефакт** и **Легендарка**, и опубликовать её как CSV для использования с веб-страницей Hall of Fame.

## Шаг 1. Создай новую таблицу

Название таблицы: `Hall of Fame — победители рулетки`

## Шаг 2. Создай лист с правильной структурой

Лист должен называться `Winners` (или любое другое имя, главное — чтобы это был **первый лист**).

В первой строке создай **строго эти заголовки** (регистр важен — должен быть нижний):

| nick | avatar_url | prize | rank | quote | date |
|------|-----------|-------|------|-------|------|

**Описание колонок:**

- `nick` — никнейм победителя на Twitch (текст, например `DragonKnight_99`)
- `avatar_url` — прямая ссылка на аватарку (например, ссылка на изображение профиля Twitch). Если оставить пустым, на карточке покажутся инициалы из ника.
- `prize` — название приза (текст)
- `rank` — **строго одно из двух значений на латинице**: `artifact` или `legendary`. Любые другие значения (включая `Артефакт` на русском) будут проигнорированы скриптом.
- `quote` — короткая цитата победителя (можно оставить пустым)
- `date` — дата в формате ISO `YYYY-MM-DD` (например `2026-03-12`)

## Шаг 3. Заполни 2-3 примера для проверки

Добавь несколько тестовых строк, например:

| nick | avatar_url | prize | rank | quote | date |
|------|-----------|-------|------|-------|------|
| TestUser1 | | Тестовый приз 1 | artifact | Это сон? | 2026-03-12 |
| TestUser2 | | Тестовый приз 2 | legendary | GG EZ | 2026-02-22 |

## Шаг 4. Защити от ошибок ввода

В колонке `rank` настрой **проверку данных** (Data validation):
- Меню: **Данные → Настроить проверку данных**
- Диапазон: вся колонка `rank` (например `D2:D1000`)
- Критерии: **Список из элементов** → ввести: `artifact,legendary`
- Действие при некорректных данных: **Отклонить ввод**

Это не даст случайно вписать опечатку или русское слово.

В колонке `date` настрой формат:
- Выдели колонку → **Формат → Число → Дата** (формат `YYYY-MM-DD`)

## Шаг 5. Опубликуй таблицу как CSV (КРИТИЧНО!)

Это самое важное — без этого веб-страница не сможет читать данные.

1. **Файл → Поделиться → Опубликовать в интернете**
2. В диалоге переключись на вкладку **«Ссылка»** (Link)
3. В первом дропдауне выбери конкретный лист `Winners` (НЕ "Весь документ" — это даст более чистый CSV)
4. Во втором дропдауне выбери **CSV** (формат значений, разделённых запятыми)
5. Раскрой раздел **«Опубликованный контент и настройки»** и **включи** опцию `Автоматически публиковать после внесения изменений`
6. Нажми **«Опубликовать»** и подтверди

Скопируй полученную ссылку — она будет вида:
```
https://docs.google.com/spreadsheets/d/e/2PACX-XXXXXXX/pub?gid=0&single=true&output=csv
```

## Шаг 6. Передай ссылку

Передай эту CSV-ссылку пользователю (или сохрани её в README), чтобы её можно было вставить в файл `index.html` в переменную `CSV_URL`.

## Шаг 7. Дай право на просмотр

Дополнительно убедись, что общий доступ к таблице на просмотр включен (на всякий случай, для совместимости): **Поделиться → Доступ → Все, у кого есть ссылка → Читатель**.

---

## Важные замечания

- **Не меняй имена колонок** — скрипт ищет их по точному названию.
- **Не удаляй и не переставляй колонки** — порядок не важен (скрипт находит по имени), но они должны существовать.
- При публикации CSV есть кэш у Google порядка 1-5 минут — если только что добавил победителя, на странице появится не мгновенно (страница автоматически обновляется раз в минуту).
- Если опубликованную ссылку нужно отозвать — там же в меню «Опубликовать в интернете» есть кнопка «Остановить публикацию».
