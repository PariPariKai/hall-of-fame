# Инструкции для Claude Code — деплой Hall of Fame на GitHub Pages

## Задача
Захостить файл `index.html` (Hall of Fame) на GitHub Pages, чтобы получить публичную ссылку, которую можно показывать в чате стрима или добавить как Browser Source в OBS.

## Что нужно от пользователя перед началом

1. Аккаунт на GitHub (если нет — создать на github.com)
2. Установленный `git` в системе (проверить: `git --version`)
3. CSV-ссылка из Google Sheets (получит из настройки таблицы по `INSTRUCTIONS_CODEX.md`)
4. Файл `index.html` из этого же набора файлов

## Шаг 1. Подставь CSV-ссылку в index.html

В файле `index.html` найди строку:
```javascript
const CSV_URL = "PASTE_YOUR_GOOGLE_SHEETS_CSV_URL_HERE";
```

Замени `PASTE_YOUR_GOOGLE_SHEETS_CSV_URL_HERE` на реальную CSV-ссылку из Google Sheets, полученную через Codex.

Должно получиться что-то типа:
```javascript
const CSV_URL = "https://docs.google.com/spreadsheets/d/e/2PACX-XXXXX/pub?gid=0&single=true&output=csv";
```

## Шаг 2. Локальная проверка (рекомендуется)

Перед публикацией проверь что всё работает локально. Из папки с `index.html` запусти:
```bash
python3 -m http.server 8000
```

Открой в браузере `http://localhost:8000` — должны появиться карточки победителей. Если видишь ошибку загрузки CSV, проверь:
- Опубликована ли таблица (см. INSTRUCTIONS_CODEX.md шаг 5)
- Правильно ли вставлена ссылка в `CSV_URL`
- Открой DevTools (F12) → вкладка Console — там будут детали ошибки

**Важно:** просто открыть `index.html` двойным кликом не сработает — браузер заблокирует fetch с `file://` протокола из соображений безопасности. Нужен именно локальный сервер.

## Шаг 3. Создай новый репозиторий на GitHub

Через веб-интерфейс GitHub:
1. Зайди на https://github.com/new
2. Имя репозитория: `hall-of-fame` (или любое другое)
3. Видимость: **Public** (приватные репо требуют GitHub Pro для использования Pages)
4. **НЕ** инициализируй с README/gitignore — оставь пустым
5. Нажми Create repository

GitHub покажет команды — обрати внимание на URL вида `git@github.com:USERNAME/hall-of-fame.git` (или `https://github.com/USERNAME/hall-of-fame.git`).

## Шаг 4. Залей файлы в репозиторий

Из папки с `index.html` выполни в терминале:

```bash
git init
git add index.html
git commit -m "Initial Hall of Fame page"
git branch -M main
git remote add origin https://github.com/USERNAME/hall-of-fame.git
git push -u origin main
```

Замени `USERNAME` на свой ник на GitHub.

При пуше потребуется аутентификация — GitHub давно отказался от паролей для git-операций, нужен либо:
- **Personal Access Token** (создать тут: https://github.com/settings/tokens — выбрать классический токен с правом `repo`, использовать вместо пароля)
- Либо **SSH ключ** (если уже настроен — используй `git@github.com:USERNAME/hall-of-fame.git` вместо https)

## Шаг 5. Включи GitHub Pages

1. На странице репозитория зайди в **Settings → Pages**
2. В разделе **Source** выбери:
   - Branch: `main`
   - Folder: `/ (root)`
3. Нажми **Save**

GitHub соберёт сайт за 1-3 минуты. Ссылка появится наверху страницы Pages, формат:
```
https://USERNAME.github.io/hall-of-fame/
```

## Шаг 6. Проверь и используй

Открой ссылку — должна появиться твоя стена победителей.

**Использование:**
- На стриме в чате — просто кидай эту ссылку зрителям
- В OBS как Browser Source — добавь источник «Browser» с этой ссылкой, размер 1920×1080, можно показывать как сцену "пауза" или фоном
- В описании канала на Twitch

## Шаг 7. Как обновлять список победителей

После настройки тебе **больше не нужно трогать GitHub** или этот файл. Workflow такой:

1. Кто-то выбивает Артефакт или Легендарку на стриме
2. Открываешь Google Sheets и добавляешь строку
3. Через минуту страница автоматически перезагружает данные (или зрители жмут F5)

Никаких ребилдов, никаких деплоев.

## Если что-то пошло не так

**Страница пустая, в консоли ошибка CORS:**
- Убедись, что используешь именно опубликованную CSV-ссылку (`/pub?...&output=csv`), а не обычную ссылку на таблицу. Только публикованные ссылки разрешают cross-origin запросы.

**Страница пустая, ошибка 404 на CSV-запросе:**
- Проверь, что во вкладке «Опубликовать в интернете» в Google Sheets публикация всё ещё активна.
- Иногда после изменения структуры листа нужно «Остановить публикацию» и опубликовать заново.

**Карточки появились, но без аватарок:**
- Поле `avatar_url` пустое или ссылка не валидна. Скрипт корректно фолбэчит на инициалы — это нормально. Чтобы добавить аватарку, открой профиль Twitch юзера, ПКМ по аве → «Копировать адрес изображения».

**Хочу свой домен вместо github.io:**
- В Settings → Pages → Custom domain укажи свой домен и добавь CNAME-запись в DNS. Это опционально.
