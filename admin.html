Подключить GitHub

Админка сохраняет данные прямо в репозиторий сайта. Для этого нужен личный токен GitHub — один раз на каждом устройстве.
  1. Открой создание токена (Fine-grained token).
  2. Token name: Админка сайта, Expiration — сколько не жалко (можно год).
  3. Repository access: Only select repositories → hall-of-fame.
  4. Permissions → Repository permissions → Contents: Read and write. Больше ничего не нужно.
  5. Generate token, скопируй и вставь сюда. Токен хранится только в этом браузере.
