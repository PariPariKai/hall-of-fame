# Инструкции для Claude Code — обновление Hall of Fame v3

## Контекст
Hall of Fame v2 уже задеплоен. Обновляем до v3 — добавляется карусель "🎰 Сейчас в рулетке" под заголовком. Это рекламный блок текущих уникальных призов в рулетке стрима.

## Что нового по сравнению с v2
- Карусель с баннерами текущих призов
- Каждый баннер — кликабелен, ведёт на Twitch (по умолчанию) или на свою ссылку
- Карусель скрыта, если призов нет (graceful degradation)
- Новый источник данных — отдельный лист в той же Google Sheets

## Что делать

### Шаг 1. Получи три значения от пользователя или из существующих файлов

Тебе нужно подставить **три переменные** в начале `index.html`:

```javascript
const CSV_URL = "...";                      // 1. Старая ссылка на Winners (была в v2)
const CURRENT_PRIZES_CSV_URL = "...";       // 2. Новая ссылка на CurrentPrizes (от Codex)
const TWITCH_URL = "https://twitch.tv/...";  // 3. Twitch-канал пользователя
```

- **CSV_URL**: бери из текущего задеплоенного `index.html` (можно из локальной копии репозитория или клонировать репо и посмотреть)
- **CURRENT_PRIZES_CSV_URL**: пользователь предоставит, или можно посмотреть в Google Sheets через "Файл → Поделиться → Опубликовать в интернете" (см. INSTRUCTIONS_CODEX_v3.md)
- **TWITCH_URL**: спроси у пользователя. На скриншотах в его GitHub Pages URL виден ник `pariparikai`, но Twitch-ник может отличаться. **Не угадывай** — спроси.

### Шаг 2. Локальная проверка

Из папки с новым `index.html`:
```bash
python3 -m http.server 8000
```
Открой `http://localhost:8000`. Проверки:

- ✅ Карусель видна под заголовком (если в `CurrentPrizes` есть хотя бы один баннер с `image_url`)
- ✅ Подпись "🎰 Сейчас в рулетке 🎰" сверху
- ✅ Карточка с баннером кликабельна и ведёт на Twitch / свою ссылку
- ✅ Если в `CurrentPrizes` пусто — карусели нет вообще (не должно быть пустого блока с заголовком)
- ✅ Все фичи v2 работают как раньше (фильтры, ранги, поиск, переворот уникальных)

Если карусель не показывается, а призы в Sheets есть — открой DevTools → Console и проверь логи. Возможные причины:
- Неправильная CSV-ссылка на `CurrentPrizes` (проверь что лист именно `CurrentPrizes` опубликован, а не `Winners`)
- Колонка `image_url` называется не точно так

### Шаг 3. Запушь в репозиторий

```bash
cp /путь/к/новому/index.html ./index.html
git add index.html
git commit -m "v3: current prizes carousel under header"
git push origin main
```

GitHub Pages обновится за 1-3 минуты.

## Важные технические детали

- **Карусель горизонтально прокручиваемая** — если призов больше чем влезает в экран, появляется горизонтальный скролл. При 1-2 призах они просто центрируются.
- **Размер баннера**: 220×440 px на десктопе, 160×320 px на мобиле. Пропорции 1:2.
- **Если у баннера нет `link` в Sheets** — клик ведёт на `TWITCH_URL` из конфига.
- **Если `TWITCH_URL` не настроен** (оставлен `YOUR_CHANNEL`) — клики не работают (ссылка `#`). Это безопасный фолбэк, но желательно настроить.
- **Карусель опциональна** — если `CURRENT_PRIZES_CSV_URL` не настроен, ошибки нет, просто блок не показывается.
- **Все ошибки загрузки текущих призов "тихие"** — пишутся только в `console.warn`, не ломают основную страницу.

## Известные особенности

- В Brave/Firefox карусель может прокручиваться плавнее если поставить курсор на неё и крутить колесом мыши (это нативное поведение horizontal overflow)
- Картинки баннеров должны быть на публичном CDN (Imgur, Discord-CDN, и т.д.). Если хостить на приватном диске — не загрузятся
