Hall of Fame v4 уже задеплоен. Обновляем до v5:

## Что РЕАЛЬНО важно проверить

**Важный момент: жёсткая миграция аватарок.**

После Codex'а в `Winners` и `Tickets` **больше нет** колонки `avatar_url`. Это значит:

- Если кого-то из победителей **нет в `Viewers`** — на главной у него будут инициалы вместо аватарки
- Если кого-то из участников билетов **нет в `Viewers`** — аналогично

Пользователю стоит проверить визуально после деплоя что все известные победители имеют аватарки. Если нет — добавить их в `Viewers`.

## Известные технические детали

- **Тиканье стрелки:** реализовано через `requestAnimationFrame`. Скрипт каждый кадр вычисляет позицию стрелки по той же easing-функции что и CSS-анимация, и когда стрелка проходит границу между секторами — запускает короткую анимацию + воспроизводит клик.
- **Web Audio API клики:** короткий "square wave" 2400→800 Hz, длительностью 60мс. Звучит как механический штифт фортуны.
- **Фанфары:** ~3-секундная мелодия из 7 нот C-мажор + финальный аккорд из 4 нот. Использует triangle и sine осцилляторы для двухслойного звука.
- **Конфетти:** 120 элементов, генерируются JS при показе победителя. Каждый элемент — div с CSS-анимацией падения. После 6 секунд контейнер очищается.
- **Авто-обновление tickets.html** каждую минуту. Wheel.html — только по кнопке "Перезагрузить билеты".
- **Кодировка:** все три файла UTF-8.

## Если что-то пошло не так

**Аватарки не показываются после миграции:**
- Проверь что `VIEWERS_CSV_URL` правильно подставлен во всех трёх файлах
- Открой DevTools → Network — проверь что запрос на `Viewers` возвращает 200 OK
- Открой Console — там логи если CSV не парсится
- Проверь что лист `Viewers` точно опубликован (не только в "Поделиться", а через "Опубликовать в интернете")

**Стрелка не дёргается во время вращения:**
- Открой Console — там логи ошибок
- Это не критическое поведение — даже без дёргания всё работает

**Конфетти/фанфары не работают:**
- Браузер требует пользовательского жеста для активации Web Audio API. Конфетти должны работать всегда, фанфары — после первого клика юзера на странице.

**Баннер таймера не виден:**
- Проверь что в `Config` есть строка `tickets_banner_url` со значением (полная URL картинки)
- Проверь что картинка доступна — открой URL в браузере отдельно
