# Инструкции для Codex — обновление Google Sheets для Hall of Fame v5

## Контекст
Hall of Fame v5 вносит **большое архитектурное изменение** — все аватарки зрителей теперь живут в одной центральной таблице `Viewers`. Это база данных зрителей.

**Что добавляется:**
1. Новый лист `Viewers` — централизованная база зрителей
2. Колонка `tickets_banner_url` в `Config` — горизонтальный баннер для фона таймера
3. **Жёсткая миграция:** удаляются колонки `avatar_url` из `Winners` и `Tickets`

**Почему так:**
- Аватарка зрителя нужна теперь в трёх местах (Hall of Fame, Tickets, Wheel)
- Дублировать `avatar_url` в каждом листе — неудобно и легко рассинхронизировать
- Один источник правды = меньше работы и ошибок
- Бонус: в `Viewers` хранится Steam-ник пользователя для отправки призов

---

## Шаг 1. Создать лист `Viewers`

Добавь новый лист в существующую таблицу. Название: `Viewers`.

Структура:

| nick | steam_nick | avatar_url |
|------|-----------|------------|

**Описание:**
- `nick` — никнейм на Twitch (точно как пишется в чате, регистр важен для отображения, но при поиске на сайте сравнение нечувствительно к регистру)
- `steam_nick` — ник в Steam для отправки подарков (только для пользователя, на сайт не выводится)
- `avatar_url` — прямая ссылка на аватарку (с Twitch, Imgur, и т.д.)

**Заполни базу зрителей** — нужно перенести всех зрителей из существующих листов `Winners` и `Tickets`:

1. Открой лист `Winners` — выпиши все уникальные ники с их `avatar_url`
2. Открой лист `Tickets` — добавь тех зрителей, которых ещё нет в списке (с их `avatar_url`)
3. Заполни этими данными лист `Viewers`
4. Колонку `steam_nick` оставь пустой — пользователь сам заполнит когда узнает Steam-ники зрителей

Пример заполнения:

| nick | steam_nick | avatar_url |
|------|-----------|------------|
| fire6545 | | https://static-cdn.jtvnw.net/jtv_user_pictures/... |
| AnyaLan | | https://static-cdn.jtvnw.net/jtv_user_pictures/... |
| Грозно Пахнет | | https://static-cdn.jtvnw.net/jtv_user_pictures/... |
| stehsha | | https://static-cdn.jtvnw.net/jtv_user_pictures/... |
| 0_pelmeshka_0 | | https://static-cdn.jtvnw.net/jtv_user_pictures/... |

## Шаг 2. Удалить колонку `avatar_url` из `Winners`

**ВАЖНО:** перед удалением убедись, что все ники из `Winners` есть в `Viewers` (см. Шаг 1). Иначе аватарки потеряются.

1. Открой лист `Winners`
2. Удали колонку `avatar_url` целиком
3. Структура `Winners` должна стать такой:

| nick | prize | rank | quote | date | unique | prize_image_url |
|------|-------|------|-------|------|--------|-----------------|

**Не паникуй:** аватарки теперь подтягиваются автоматически из `Viewers` по нику.

---

## Шаг 3. Удалить колонку `avatar_url` из `Tickets`

Аналогично:

1. Открой лист `Tickets`
2. Удали колонку `avatar_url`
3. Структура `Tickets` должна стать:

| nick | silver | gold |
|------|--------|------|

## Шаг 4. Добавить `tickets_banner_url` в `Config`

В существующий лист `Config` добавь новую строку:

| key | value |
|-----|-------|
| ...предыдущие строки... | |
| **tickets_banner_url** | (ссылка на горизонтальный баннер, либо оставить пустым) |

**Описание:**
- `tickets_banner_url` — прямая ссылка на горизонтальный баннер, который будет фоном таймера на странице `tickets.html`. Пользователь сам подготовит баннер (примерно 1600×400 px, горизонтальный).
- **Если оставить пустым** — таймер показывается с обычным градиентом без баннера
- **При активной фазе ивента** — пользователь вписывает ссылку, и баннер появляется
- **Между ивентами** — пользователь может очистить ячейку и оставить таймер с простым фоном

Пример пустого состояния (до подготовки баннера):
| tickets_banner_url | |

Пример с баннером:
| tickets_banner_url | https://i.imgur.com/subnautica_banner_horizontal.png |

---

## Шаг 5. Опубликовать новый лист `Viewers` как CSV

1. **Файл → Поделиться → Опубликовать в интернете**
2. В первом дропдауне выбери лист **`Viewers`**
3. Во втором — **CSV**
4. Опубликовать → подтвердить
5. Скопируй ссылку — это `VIEWERS_CSV_URL`

---

## Шаг 6. Передать данные пользователю

Передай пользователю:

1. **VIEWERS_CSV_URL** — новая ссылка на лист `Viewers`
2. Подтвердить что миграция выполнена (колонки `avatar_url` удалены из `Winners` и `Tickets`)
3. Подтвердить что строка `tickets_banner_url` добавлена в `Config`

---

## Итоговая структура таблицы после миграции

5 листов:

| Лист | Колонки | Назначение |
|------|---------|-----------|
| **Winners** | nick, prize, rank, quote, date, unique, prize_image_url | Стена победителей |
| **CurrentPrizes** | image_url, title, link, active | Карусель на главной |
| **Tickets** | nick, silver, gold | Билеты участников |
| **Config** | key, value (включая tickets_banner_url) | Общие настройки |
| **Viewers** | nick, steam_nick, avatar_url | **База зрителей (новая)** |

## Замечания

- **Сравнение ников нечувствительно к регистру.** Если в `Winners` ник записан как `fire6545`, а в `Viewers` как `Fire6545` — аватарка всё равно подтянется.
- **Если зрителя нет в `Viewers`** — на сайте показываются его инициалы как фолбэк. Это нормальное поведение для новых зрителей пока ты не успел добавить их в базу.
- **При добавлении нового победителя/билетного зрителя**: сначала добавь его в `Viewers` (если ещё нет), потом в `Winners`/`Tickets`. Это правильный workflow.
- **CSV-ссылки на `Winners`, `Tickets`, `Config`, `CurrentPrizes` не меняются** при удалении/добавлении колонок. Все старые ссылки продолжают работать.
- **Не удаляй сразу `avatar_url` из старых листов**, если не уверен что все ники перенесены — лучше сначала переноси по одному и проверяй на сайте.
